REPLIT BUILD INSTRUCTION (USE AS-IS)
Project Goal

Build a licensed custodial crypto investment platform that supports real crypto deposits and withdrawals on a single blockchain, using:

Frontend: Next.js (Vercel-ready)

Backend: Node.js API (Render-ready)

Database: Supabase (PostgreSQL + Auth)

Blockchain: ONE chain only (configurable via env)

Custody: EOA wallet controlled by backend (manual withdrawals only)

This is NOT a simulation. Real blockchain transactions must be supported.

1. Mandatory Project Structure

Create a monorepo:

/crypto-investment-platform
  /frontend     → Next.js 14 (TypeScript, App Router)
  /backend      → Node.js API (TypeScript)
  /shared       → shared types & validation schemas
  README.md
  .env.example


Frontend and backend MUST be fully separated.

4. Blockchain Responsibilities (REAL FUNDS)
Deposit Handling (Automatic)

Backend listens for incoming transactions to DEPOSIT_WALLET_ADDRESS

Valid deposit only if:

tx.to === deposit address

tx.status === success

confirmations ≥ threshold

Backend credits user internal balance

Save:

tx hash

block number

amount

chain id

Withdrawal Handling (MANUAL)

User submits withdrawal request

Admin approves request

Admin manually signs tx (or backend signs after admin approval)

Backend records tx hash

NO automatic withdrawals

6. Security Rules (NON-NEGOTIABLE)

Enable Supabase Row Level Security

Users can only read their own records

Backend is the ONLY writer for balances

All blockchain txs verified backend-side

Admin-only routes protected by role check

Never log private keys

Never expose service role key
